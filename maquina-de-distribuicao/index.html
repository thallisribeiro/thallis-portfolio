Máquina de Distribuição

Um sistema para transformar uma ideia, uma notícia ou uma pesquisa em distribuição recorrente — blog, SEO, X, vídeo e carrossel — a partir de uma apuração só.

Antes de qualquer coisa: isso ainda não está à venda. Não tem preço, não tem data e não tem checkout nesta página. O que existe é o sistema rodando pra mim — é ele que publica o que está no blog deste site.

O problema que ele resolve

O trabalho caro é achar uma história que preste, apurar, conferir se é verdade e decidir o ângulo. Isso leva horas. Publicar o resultado em quatro lugares diferentes deveria ser o barato da operação — e na prática é onde tudo trava, porque cada canal pede uma linguagem própria.

O resultado é conhecido: a pessoa apura bem uma vez, publica num canal só, e a mesma apuração morre ali.

Como funciona

Uma entrada, vários canais. A apuração acontece uma vez e vira uma história-mãe; dela saem as versões de cada canal, cada uma com a linguagem daquele canal, mantendo a mesma tese.

O que eu já aprendi construindo

A parte que mais me surpreendeu não foi gerar texto. Foi descobrir que um modelo não dá o mesmo veredito duas vezes sobre o mesmo texto. Ele reprovou uma peça apontando dois erros e, sobre o arquivo idêntico, aprovou a mesma peça minutos depois.

Por isso a checagem de fato virou código determinístico, separada do julgamento editorial: mesmo texto, mesmo veredito, sempre. O modelo opina sobre o que é bom. Ele não decide o que é verdade.

Esse tipo de coisa vai virando post no blog conforme acontece.
