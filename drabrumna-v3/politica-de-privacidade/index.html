Política de Privacidade

Como os dados de quem visita este site são tratados, conforme a Lei Geral de Proteção de Dados.

Documento em elaboração

Este texto é uma minuta de trabalho e precisa de revisão jurídica antes da publicação. Os campos entre colchetes dependem de informação da cliente.

Quais dados são coletados

Este site coleta dados de navegação de forma agregada, por meio de ferramenta de medição de audiência, e apenas depois do seu consentimento. Se você iniciar uma conversa pelo WhatsApp, os dados dessa conversa são tratados dentro do próprio aplicativo, conforme as políticas da plataforma.

Dados de saúde

Este site não coleta dados de saúde. Informações clínicas são tratadas exclusivamente na consulta médica presencial, com o sigilo profissional aplicável.

Finalidade

Os dados de navegação são usados para entender como as páginas são utilizadas e melhorar o conteúdo. Não há venda, cessão ou uso publicitário de dados pessoais.

Seus direitos

A Lei Geral de Proteção de Dados garante acesso, correção, exclusão, portabilidade e revogação de consentimento. Os pedidos podem ser feitos pelo contato indicado ao final desta página.

Retenção e segurança

Os dados de navegação são mantidos pelo período configurado na ferramenta de medição e depois descartados. As medidas técnicas de segurança devem ser detalhadas na versão final deste documento.
