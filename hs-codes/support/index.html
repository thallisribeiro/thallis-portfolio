Getting started

  1. Install. The app isn't on the Shopify App Store yet. Ask to be notified and you'll get one email when it's listed. Shopify asks you to approve reading products and updating inventory items.
  2. Scan. On the Dashboard, press Scan catalog. You'll see how many variants miss an HS code, a US HTS code or a country of origin.
  3. Suggest. On Products, tick the products to classify and press Suggest codes with AI. Each suggestion counts toward your monthly allowance (25 on Free, 500 on Pro, 2,000 on Plus).
  4. Review. On Review, read each suggestion: its confidence, its reasoning and the result of the check in the US schedule.
  5. Apply. Apply writes the HS code and the US HTS code to every variant of the product. Your country of origin isn't touched; set it on Products (Set origin) or on the product's page.

Suggestions are not customs advice. You're responsible for the codes you file.

CSV format

On Import / export, Export CSV downloads every variant. Edit the file and import it back. A blank cell leaves that value unchanged. If any row has a problem, nothing is written and every problem is listed with its line number. A file can have up to 250 rows; split bigger ones.

ColumnOn importFormat
Variant IDRequiredThe gid://shopify/ProductVariant/… ID from the export (the number alone also works). Rows are matched by it.
Product, Variant, SKUIgnored on importFor your reference while editing.
HS codeOptional6 to 13 digits; dots and spaces are fine (6109.10). Excel's lost leading zero is put back.
US HTS codeOptionalExactly 10 digits (6109.10.00.12). A 9-digit value gets its leading zero back.
Country of originOptionalTwo-letter country code, like CN, US or PT.

Troubleshooting

“AI suggestions are unavailable right now”

The app can't reach the AI service at the moment. Scanning, manual editing, setting origin and CSV still work. If it lasts, write to xthallis@gmail.com.

“Couldn't check”

The US tariff schedule (USITC) didn't answer within 8 seconds, so the US HTS code wasn't verified. The suggestion is saved anyway. “Apply all verified high-confidence” skips it; check the code at hts.usitc.gov and apply it by hand, or ask for a new suggestion later.

“Not in US schedule”

The suggested US HTS code doesn't exist in the current US schedule. The app lists the valid codes under the suggested 6-digit heading; pick the one that fits and press Apply. Apply never writes a code that isn't in the schedule.

A product shows “Varies”

Its variants have different values. Open the product to see each variant, then save one value for all of them or fix them in a CSV.
